Bundled plugins

VST3 plugins in this folder ship with this copy of PULP. PULP looks at any it has not seen
before when it starts, so they appear in the plugin lists on the first run.

They are separate programs, loaded while PULP runs, with their own licences. For example,
NoDAW Screw (by NoDAW Labs) is proprietary, a 14-day trial that is activated with a license key;
it is not part of PULP and not covered by PULP's licence (AGPL-3.0).

PULP's source code: https://github.com/myaiplug/pulp-daw-public
